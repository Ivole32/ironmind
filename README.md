## 🎯 The Goal

My challenge is to build a complete digit recognition neural network in Rust, using as few external crates as possible.

The only resources I'm allowing myself are the official Rust documentation and general mathematical documentation unrelated to neural networks or AI. I'm starting without any real experience in Rust or neural networks, so I'll have to figure out both along the way.

I also want to keep this challenge entirely independent. No AI assistance, no external help with the research, and no tutorials on neural networks. Just my limited existing knowledge, official documentation, and the willingness to learn through experimentation.

To keep everything transparent, I'll document the entire journey, including my thoughts, decisions, mistakes, experiments, and progress. The goal isn't just to make it work. It's to understand how everything works under the hood and see how far I can get on my own.

## 📜 The Rules (Short Version)

| | Rule |
|---|---|
| 🤖 | **No AI**, except for fixing spelling and wording in documentation and polishing documents that explain the project, like this README. Never in code. |
| 📚 | **Only official docs**: the Rust documentation, docs of crates I use, and math unrelated to neural networks. |
| 📦 | **As few crates as possible.** |
| 🗂️ | **Public datasets are allowed**, properly cited according to their license. |
| 📝 | **Document everything**: thoughts, research, mistakes, and every change to the rules. |
| 🏁 | **Done at 95%** accuracy on test data it was never trained on, and only once I can't find anything left to optimize. |

The full rules are in [RULES.md](RULES.md).
